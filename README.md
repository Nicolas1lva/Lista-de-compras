# 🛒 Lista de Compras
 
Projeto desenvolvido em HTML, CSS e JavaScript.
 
## Funcionalidades atuais
 
- Adicionar itens
- Definir quantidade
- Informar valor unitário
- Cálculo automático do subtotal
- Cálculo automático do valor total
- Mostrar e ocultar formulário de cadastro
 
## Próximas funcionalidades
 
- Checkbox para itens comprados
- Total dos itens comprados
- Exclusão de itens
- Persistência dos dados (LocalStorage)
- Melhorias visuais
- Versão Android (PWA/APK)

## 🛠 Tecnologias utilizadas
 
- HTML5
- CSS3
- JavaScript
 
## 📷 Versão Atual
 
Atualmente a aplicação permite adicionar produtos à lista e calcular o valor total da compra em tempo real.
 
## 🎯 Objetivo do Projeto
 
Este projeto está sendo desenvolvido como forma de aprendizado prático de JavaScript, manipulação de DOM, eventos e lógica de programação.
